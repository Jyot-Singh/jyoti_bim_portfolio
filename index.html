04BIM automation

pyRevit tools I built to remove the boring work

Each tool replaces a tedious, error-prone manual routine in Revit with a single click. Press play to watch a short demo of each one.

Tool 01

Automated Room Finishes

The manual way

Tediously tracing the perimeter of every single room to individually model the skirting, floor layers and wall plaster.

The solution

Read the room boundaries and instantly generate all architectural finishes in one click.

Tool 02

Automated Room Numbering

The manual way

Clicking each room one by one, typing the number, realizing you missed one, and having to fix the entire sequence by hand.

The solution

Select the space, define the format, and correctly number all rooms across the floor in one click.

Tool 03

Auto-Dimensioning Tool

The manual way

Clicking every single wall face, struggling to match the spacing between dimension lines, zooming in and out, and obsessively readjusting.

The solution

Decide your spacing once and generate perfectly aligned, standardized dimensions in one click.

Tool 04

Grid Alignment Utility

The manual way

Manually moving the grid on 50+ sheets, drawing temporary reference lines to check, and fighting to keep it consistent everywhere.

The solution

Snap all grid heads and tails to a perfect, unified alignment across the entire project in one click.

Tool 05

Bulk Wall Type Management

The manual way

Making 100+ wall types, duplicating and renaming them, then going back and forth to update descriptions and keynotes.

The solution

Update everything in Excel, import all changes into Revit at once, and export back to Excel to keep handy during client meetings.
